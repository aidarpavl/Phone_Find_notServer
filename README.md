# 📍 Локатор устройств (семейный локатор)

Streamlit-приложение: добавляешь устройства по номеру телефона, видишь их на
карте **2GIS**, и можешь попросить нужное устройство громко **зазвонить**, чтобы
найти его ещё и по звуку.

## ⚠️ Важно про то, как это работает

Приложение построено по **согласной модели** — как «Найти устройство» от Google
или семейные локаторы (Life360, «Локатор» Apple):

- Устройство появляется на карте, **только если на нём открыто это приложение**
  в режиме «Моё устройство» и оно само делится своим GPS.
- Номер телефона используется как **идентификатор** устройства, а не как способ
  узнать чужое местоположение.

**Чего приложение НЕ делает (и не может делать законно):** определять
местоположение чужого телефона по одному лишь номеру, без установки приложения
и без согласия владельца. Так работает только шпионское ПО или взлом сети
оператора — это незаконно. Любой «сервис», обещающий такое по номеру, — обман
либо преступление.

## Возможности

- ➕ Добавление устройства по номеру телефона
- 📲 Режим «Моё устройство»: телефон делится GPS (с разрешения браузера)
- 🗺 Карта **2GIS MapGL** с маркерами устройств (запасной вариант — OpenStreetMap)
- 🔔 Кнопка «Подать сигнал»: целевое устройство громко проигрывает звонок
- 🔄 Автообновление карты и позиций

## Установка и запуск

```bash
git clone https://github.com/<ваш-логин>/phone-locator.git
cd phone-locator
pip install -r requirements.txt
streamlit run app.py
```

Откройте в браузере адрес, который покажет Streamlit (обычно
`http://localhost:8501`).

## Ключ карты 2GIS

Карта 2GIS MapGL требует бесплатный ключ:

1. Зарегистрируйтесь на <https://dev.2gis.ru/>.
2. Создайте ключ для **MapGL JS API**.
3. Вставьте ключ в поле на боковой панели приложения,
   либо задайте его в `.streamlit/secrets.toml`:

```toml
DGIS_KEY = "ваш-ключ-2gis"
```

Без ключа приложение покажет карту OpenStreetMap, всё остальное работает.

## Как пользоваться

1. На своём телефоне откройте приложение → режим **«Моё устройство»** → введите
   номер → разрешите геолокацию и один раз нажмите «Разрешить звук».
2. На другом устройстве откройте режим **«Искать устройства»** → добавьте тот же
   номер → смотрите точку на карте.
3. Нажмите **«🔔 Подать сигнал»** — телефон в режиме «Моё устройство» зазвонит.

## Общая БД — чтобы работало между разными телефонами без своего сервера

Приложение само выбирает хранилище по настройкам (в порядке приоритета):

| Условие | Бэкенд |
|---|---|
| задан `DATABASE_URL` | **Postgres** (Supabase / Neon) |
| заданы `FIREBASE_PROJECT_ID` + `FIREBASE_API_KEY` | **Firebase Firestore** |
| ничего не задано | **SQLite** (локальный файл, одна машина) |

Можно форсировать: `DB_BACKEND = postgres | firebase | sqlite`.
Активный бэкенд показан в боковой панели приложения.

Настройки задаются через **Streamlit secrets** — файл `.streamlit/secrets.toml`
локально, или раздел *Secrets* в настройках приложения на Streamlit Cloud.

### Вариант А — Postgres (рекомендуется, проще всего)

1. Создайте бесплатную БД на [Supabase](https://supabase.com) или
   [Neon](https://neon.tech).
2. Скопируйте строку подключения (Connection string, формат
   `postgresql://user:pass@host:5432/dbname`).
3. В secrets:

   ```toml
   DATABASE_URL = "postgresql://user:pass@host:5432/dbname"
   DGIS_KEY = "ваш-ключ-2gis"
   ```

   Таблица создаётся автоматически при первом запуске.

### Вариант Б — Firebase Firestore

1. Создайте проект на [console.firebase.google.com](https://console.firebase.google.com),
   включите **Firestore Database**.
2. Возьмите **Project ID** (настройки проекта) и **Web API Key**
   (настройки → «Ваши приложения» → веб-приложение).
3. В secrets:

   ```toml
   FIREBASE_PROJECT_ID = "my-project-id"
   FIREBASE_API_KEY = "AIza..."
   DGIS_KEY = "ваш-ключ-2gis"
   ```

4. Для демо включите в правилах Firestore доступ к коллекции `devices`.
   Для продакшена обязательно настройте аутентификацию и правила доступа —
   открытый Firestore увидит кто угодно.

### Деплой на Streamlit Community Cloud (бесплатно, без своего сервера)

1. Запушьте репозиторий на GitHub.
2. На [share.streamlit.io](https://share.streamlit.io) → *New app* → выберите
   репозиторий и `app.py`.
3. В *Advanced settings → Secrets* вставьте настройки БД и `DGIS_KEY`.
4. Получите публичную ссылку — открывайте её с любого телефона.

## Ограничения

- SQLite работает только в пределах одной машины — для нескольких телефонов
  используйте Postgres или Firebase (см. выше).
- Для серьёзного продакшена добавьте аутентификацию пользователей, строгие
  правила доступа к БД и push-уведомления.
